# CLAUDE.md — GAA Video Analytics

Open-source Gaelic football video analytics for grassroots clubs. Apache-2.0.

## Principle
Never fabricate statistics. Every stat is computed from events; every event has
`provenance` (`source`: manual|cv, `status`: observed|inferred|verified|unknown).
CV output is a **candidate** (`cv.candidates`) and never counts until a person
accepts it. Categories not declared in `coverage` are reported as `unknown` (null), never 0.

## Layout
- `web/` — static Vite + TypeScript app (GitHub Pages). No backend.
  - `src/core/` — contract (`types.ts`), rules (`rules.ts`, `SportRules`), stats engine
    (`stats.ts`), validation (`validate.ts`), exports (`export.ts`), doc helpers (`document.ts`).
    Pure TS, no DOM. **Single source of truth for statistics.**
  - `src/ui/`, `src/main.ts` — DOM UI (tagging, review, CV candidates, stats, printable report).
  - `public/samples/demo-match.json` — FICTIONAL demo (`demo: true`), generated by `scripts/make-demo.mjs`.
  - `scripts/fetch-model.mjs` — downloads YOLOX-nano ONNX for optional in-browser single-frame detection.
- `processor/` — optional local Python CV pipeline (`gaa_cv`): OpenCV video → YOLOX ONNX
  (onnxruntime) → supervision ByteTrack → jersey-colour clustering → ball/possession
  heuristics → analysis JSON with candidates. Weights downloaded by `scripts/download_models.py`.
- `schema/analysis.schema.json` — JSON Schema of the contract (mirrors `types.ts`; tested with ajv).
- `docs/research/` — research notes (CV projects, GAA rules, test footage).

## Commands
- Web: `cd web && npm ci && npm test && npm run build` (`npm run dev` for local).
- Processor: `cd processor && pip install -e '.[dev]' && python scripts/download_models.py && python -m pytest -q`
- Analyse: `python -m gaa_cv analyse match.mp4 --out match.analysis.json --profile veo`

## Conventions
- Contract changes: update `types.ts`, `schema/analysis.schema.json`, `validate.ts`, processor output and tests together.
- Rules: GAA scoring lives only in `rules.ts` (`gaa-football-2025` id = 2025/2026 rules: goal 3, point 1,
  kicked score from outside 40m arc 2). Score value comes from the recorded outcome; rule checks are warnings.
- No AGPL/GPL code or weights (excludes Ultralytics YOLOv8/11). Do not commit video or model weights.
- Escape user text in the UI; CSV export guards against formula injection.

## Status (v0.1.0)
Working: manual tagging → stats → printable report, JSON/CSV export/import, CV processor
(person detection + tracking + team colour clusters + visible-ball + possession-change candidates).
Not implemented: automatic shot/score/kick-out recognition, pitch calibration, player identity.
